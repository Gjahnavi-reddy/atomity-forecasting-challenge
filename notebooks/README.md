# Notebooks

Interactive workload exploration and analysis for the Azure VM dataset.

## Contents

- `01_exploratory_workload_analysis.ipynb`: Walkthrough covering raw telemetry ingestion, aggregate target calculation (`active_vm_count` and `aggregate_cpu_utilization`), workload segmentation by VM category, and rolling-origin cross-validation.

## Running

```bash
jupyter notebook notebooks/01_exploratory_workload_analysis.ipynb
```
